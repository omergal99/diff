# Next steps for Diffinity

## Short-term improvements
- Fix the remaining edge cases in inline word highlighting for very long or heavily transformed lines.
- Add a clearer empty-state message when the user has not entered any text yet.
- Improve the mobile / narrow-screen layout for the split view.

## Medium-term ideas
- Add support for side-by-side file upload comparison directly from the UI.
- Show a summary panel with statistics and quick actions after each comparison.
- Add keyboard shortcuts for navigation between diff hunks.

## Longer-term roadmap
- Add Git integration for comparing branches and commits.
- Add support for 3-way merge workflows.
- Expand the backend to support richer file-type comparisons (PDF, DOCX, images) in a polished UI.
